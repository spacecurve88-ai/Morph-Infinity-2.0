# 0.1.0 — independent successor foundation

First executable application in this repository. Create local workspaces, preview and approve reading/budget templates, edit records, compute arithmetic fields, capture abandonment dates, chart monthly counts, create relations, switch table/card views, fork branches, compare and restore history, and export/restore native JSON backups. Production assets are cached for offline loading.

This early build includes strict validation and transactional protection against stale writes, corrupt backups and failed quota writes. No paid service or AI is required.

Not a verified v8 migration or a complete product release. Legacy backups safely reject until real fixtures are available. No automatic merge, general natural-language understanding, reminders, arbitrary code, timer runtime, AI model or cloud sync. A separate [GitHub Pages preview](deployment.md) is now deployed and has passed automated Chromium/WebKit smoke checks. Physical iPad testing remains required. See the roadmap and recorded test coverage before relying on release gates.

# Deterministic simulation increment

Generalized version-1 conditions, simulation/record triggers, typed assignments/increments/decrements/state transitions, correlated sum/count and aggregate computed fields are integrated into the workbench. Users can create/edit/enable/disable/remove rules through forms, preview bounded steps with ordered changes, download the full preview, approve one atomic branch-local revision, and restore it through history. An economic example exercises ordinary generic rules; the engine has no economic-specific execution.

Old native format-2 data is accepted without migration or inserted defaults. New automation definitions are optional versioned extensions retained by backup/restore. Global work/output limits, per-view budgets, bounded aggregate caches, record pagination and a cancellable worker protect the interface. Unsupported capabilities, stale writes, conflicts, quotas and malformed input reject without partial persistence.

Physical iPad testing of the new simulation interface remains pending; the handoff's six successful physical checks are user-reported baseline evidence only. Average aggregates, general scheduling, arbitrary code, AI, automatic merge, scalable history compaction and genuine v8 migration remain outside this release.
