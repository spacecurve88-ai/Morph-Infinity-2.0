# 0.1.0 — independent successor foundation

First executable application in this repository. Create local workspaces, preview and approve reading/budget templates, edit records, compute arithmetic fields, capture abandonment dates, chart monthly counts, create relations, switch table/card views, fork branches, compare and restore history, and export/restore native JSON backups. Production assets are cached for offline loading.

This early build includes strict validation and transactional protection against stale writes, corrupt backups and failed quota writes. No paid service or AI is required.

Not a verified v8 migration or a complete product release. Legacy backups safely reject until real fixtures are available. No automatic merge, general natural-language understanding, reminders, arbitrary code, timer runtime, AI model, cloud sync or deployment. Physical iPad testing remains required. See the roadmap and recorded test coverage before relying on release gates.
