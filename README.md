# Morph Infinity 2.0

A local-first, AI-assisted environment for creating and evolving custom software through natural-language requests.

## Project status

This repository has been initialized for development with OpenAI Codex. It does not yet contain the Morph Infinity application source code.

## Development goals

- Build a responsive, iPad-friendly web application.
- Preserve user data, with reliable backups and recovery.
- Support safe, validated feature plans, computed fields, rules, views, and branching.
- Keep basic functionality usable without paid APIs or an AI model.
- Add automated tests for data integrity, feature behaviour, and restoration.
